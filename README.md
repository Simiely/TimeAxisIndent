# TimeAxisIndent · AE 时间轴错位显示工具

一个极简的 After Effects 2026 脚本面板 —— 给时间轴图层名添加**前导缩进**,让图层在时间轴里**左侧错位显示**,一眼就能区分不同图层内容。

> 核心设计:**只改图层名字,不碰父子结构、不动关键帧、不影响动画和渲染。**
> 没装这个脚本,工程照常打开、图层正常显示 —— 缩进只是图层名称的一部分,固化成普通文字而已。

## 特性

- 左侧错位:全角空格 / 树形符号 `├- ` 两种缩进字符(默认树形符号)
- 等距缩进 或 按时间轴顺序逐层递进(0、1、2…格),缩进量 1~3 格
- **应用方式可切换**:叠加缩进(逐次加深,1 格 → 2 格 → 3 格)或 清空重排(先清后统一)
- 作用范围:仅选中图层 或 整个合成;多风格可分批共存、互不干扰
- 按风格还原(按当前字符 / 全部清除),所有操作 Ctrl+Z 一次整体撤销
- 面板内状态栏显示操作结果,不弹窗打扰
- 免安装,单个 .jsx 文件,复制即用

## 安装(免安装)

1. 把 `TimeAxisIndent.jsx` 复制到 AE 脚本面板目录,例如:
   ```
   %APPDATA%\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\
   ```
   (或系统级 `...\Adobe After Effects 2026\Support Files\Scripts\ScriptUI Panels\`,需管理员权限)
2. 重启 AE(脚本面板启动时扫描)。
3. 菜单「**窗口 › 扩展 › 时间轴错位显示**」打开面板。

## 快速开始

1. 在时间轴中激活一个合成(可选:选中部分图层)。
2. 保持默认参数(应用方式=叠加、字符=树形、1 格、递进),点「**应用错位**」。
3. 图层从左到右错落排开,层级一目了然。
4. 想恢复:点「**还原错位**」或直接 **Ctrl+Z**。

### 效果示例(递进 + 树形 1 格)

```
图层 A            ← 原样
├- 图层 B        ← 缩 1 格
├- ├- 图层 C    ← 缩 2 格
├- ├- ├- 图层 D ← 缩 3 格
```

## 常用操作

| 目标 | 操作 |
| --- | --- |
| 逐次加深一批层 | 选中 → 应用方式=叠加 → 连点「应用错位」 |
| 整体换风格重排 | 应用方式=清空重排 → 点「应用错位」 |
| 只撤某批某风格 | 选中该批 → 还原方式=按当前字符 → 「还原错位」 |
| 一次清光所有缩进 | 还原方式=全部清除 → 「还原错位」 |
